E9 Fog of War — Design (3/3): Visualizer

One decision: how opaque is the MEMORY state?

UNSEEN (never seen) is always solid black. VISIBLE is always clear. The question is MEMORY — terrain you've visited but can't currently see. Two valid readings:
N
A — Memory at 75% black. Clear boundary between visited and not.

A — Heavy memory (75% black)

Strong distinction between UNSEEN and MEMORY. Terrain shape is barely readable. Feels closer to SC2's darker fog. You know you've been there — that's about it.

N
B — Memory at 45% black. Terrain clearly readable in visited areas.

B — Light memory (45% black)

Visited terrain is clearly readable — terrain type, height, and map layout stay legible. More useful for an R&D tool where you want to understand what the agent has explored.

Both render with a single PixiJS Graphics pass. This is purely aesthetic — pick whichever feels right.
