E9 Fog of War — Design (2/3): Server-Side Filtering & Broadcast

How visibility flows from EmulatedGame to the agent and the visualizer

EmulatedGame changes

// New field — persists across ticks
private final VisibilityGrid visibility = new VisibilityGrid();

// Called inside tick(), after friendly units move
visibility.recompute(myUnits, myBuildings, terrainGrid);

// observe() filters before returning
List<Unit> visibleEnemies = enemyUnits.stream()
  .filter(u -> visibility.isVisible(u.position()))
  .toList();

// New accessor for broadcaster
VisibilityGrid observeVisibility() { return visibility; }

enemyStagingArea is also filtered — staging units sit at HIGH ground, so they're invisible from LOW until scouted. The agent's GameState becomes genuinely limited.

Routing visibility to the broadcaster

The SC2Engine interface stays clean — no visibility concept leaks in. Instead, EmulatedEngine (the CDI bean wrapping EmulatedGame) exposes visibility as a CDI @ApplicationScoped holder updated each tick. The broadcaster injects it optionally.

// EmulatedEngine — updates after each tick
visibilityHolder.set(game.observeVisibility());

// VisibilityHolder — CDI bean, null in mock/replay/SC2 modes
@ApplicationScoped class VisibilityHolder {
  private volatile VisibilityGrid current;
  void set(VisibilityGrid g) { current = g; }
  VisibilityGrid get() { return current; } // null if not emulated
}

// GameStateBroadcaster — injects holder, sends visibility if present
@Inject VisibilityHolder visibilityHolder;
broadcast({ gameState, visibility: visibilityHolder.get() });

WebSocket payload

The broadcaster wraps GameState + visibility grid into a new broadcast record. Existing fields unchanged — visibility is additive and nullable.

record GameStateBroadcast(
  GameState state,
  int[][] visibility // [x][y]: 0=UNSEEN 1=MEMORY 2=VISIBLE; null if not emulated
)

64×64 ints = 4096 values per frame. Compact, fast to serialize. Visualizer checks for null and skips fog rendering in non-emulated modes.

Other engine modes — unaffected

Mock
No VisibilityHolder update. broadcast.visibility = null. Visualizer shows all enemies as before.
Replay
Same — no visibility. Full enemy state visible (observe-only mode anyway).
Real SC2
SC2 engine handles fog natively — GameState already contains only visible units.
