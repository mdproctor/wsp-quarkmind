E9 Fog of War — Design (1/3): Core Model

VisibilityGrid, sight ranges, and high-ground rules

VisibilityGrid

New domain class VisibilityGrid — a 64×64 grid of tile states, computed by EmulatedGame each tick and persisted between ticks (MEMORY accumulates).

enum TileVisibility { UNSEEN, MEMORY, VISIBLE }

class VisibilityGrid {
  TileVisibility[][] tiles; // [x][y], persists across ticks
  void recompute(List<Unit> friendly, List<Building> buildings, TerrainGrid terrain)
  TileVisibility at(int x, int y)
  boolean isVisible(Point2d pos)
}

Each tick: tiles that were VISIBLE become MEMORY if no longer in vision. New VISIBLE tiles are added from current observer coverage. MEMORY never reverts to UNSEEN.

High Ground Visibility Rule (official SC2)

Observer on LOW / RAMP → vision covers only LOW and RAMP tiles. HIGH tiles are never made VISIBLE, regardless of range.
Observer on HIGH → vision covers HIGH, RAMP, and LOW tiles normally.

Consequence: the entire enemy staging area is invisible until a probe reaches HIGH ground. Scouting becomes genuinely meaningful.
