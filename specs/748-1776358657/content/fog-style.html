Fog of War — Visual Style

How should unexplored / out-of-vision areas look in the visualizer?

N
A — Solid dark fog

A — Solid Dark

Unexplored areas are pitch black. Classic SC2-style. Sharp contrast, unambiguous. Revealed terrain stays lit; re-fogged areas go dark again.

N
B — Translucent fog, terrain visible beneath

B — Translucent Dim

Fog is a semi-transparent dark overlay — terrain shape still readable through it. Less dramatic but very readable for an R&D tool.

N
C — Dark=unseen · Grey=memory · Lit=visible

C — Shroud + Memory

Three states: black (never seen), grey (seen but currently out of vision — terrain remembered, units hidden), lit (currently visible). Most game-accurate SC2 style.

All options: units only appear in currently lit areas. The difference is how terrain looks in the dark zones.
